# Scramble Ritual — 제작 플랜 (2026-06-11 기준)

목표: 웨이브폼 오브제를 카메라로 인식해 사운드가 반응하는 인터랙티브 설치를 완성하고,
이후 144채널 릴레이 매트릭스를 통합한다. 현장공유 목표 시점: 10–11월.

## 진행 상황 요약

| 서브시스템 | 상태 |
|---|---|
| 비전 트래커 (위치·기울기·접촉·겹침 → 사운드 파라미터) | ✅ 합성 영상으로 검증 완료, 27fps |
| 내장 그래뉼러 신스 + 마우스 샌드박스 (실제 소리) | ✅ 완성 — 콜백 0.16ms/10.67ms |
| OSC 송출 + Max/MSP 명세 (docs/osc-map.md) | ✅ 코드 완성 / ⬜ 실연동 미검증 |
| 144ch 릴레이 (펌웨어 + 호스트 + 시뮬레이터) | ✅ 시뮬레이션 검증 완료 / ⬜ 실보드 미검증 |
| 실카메라·실물 오브제 | ⬜ 오브제 미확보 — Phase 2를 먼저 진행 (6/11 결정) |

---

> **순서 변경 (6/11)**: 피지컬 오브제가 아직 없어 Phase 2(사운드)를 먼저 진행한다.
> 마우스 샌드박스가 오브제 입력을 대신하므로 Phase 1 없이도 사운드 작업이 가능하다.

## Phase 1 — 실물 인식 검증 (오브제·카메라 확보 후)

카메라와 실제(또는 목업) 오브제로 트래커를 검증·튜닝한다.

**준비물 (직접)**
- [ ] 카메라 1대 — 시작은 일반 웹캠으로 충분, IR 전환 여부는 Phase 1 결과로 결정
- [ ] 오브제 4개 — 실물이 없으면 검은 종이/폼보드로 웨이브폼 목업
- [ ] 균일 배경(흰/검 매트) + 고정 조명

**작업 (Claude)**
- [ ] 테스트 영상 기준 파라미터 튜닝 (`invert`, `min_area_px`, `contact_gap_px`)
- [ ] 검출 안정성 측정 도구: 각도/위치 지터, ID 스왑 횟수 자동 리포트
- [ ] 필요 시: 렌즈 왜곡 보정·테이블 영역 호모그래피(사각 영역 → 정규좌표)

**완료 기준**
- 실영상에서 오브제 4개를 30fps로 추적, 1분간 ID 스왑 0회
- 정지 오브제의 각도 지터 ±3° 이내, 접촉/겹침 이벤트 오발 없음

> 가장 빠른 진행법: 오브제를 놓고 움직이는 모습을 1–2분 촬영해서 영상 파일을 주면
> (`--video`로 재생) 하드웨어 없이도 튜닝을 끝낼 수 있음.

## Phase 2 — 사운드 구현·실연동 (6–7월) ← 진행 중

오브제 없이 "조작 → 소리 변화"를 완성한다. 입력은 마우스 샌드박스가 대신한다.

**작업**
- [x] 내장 그래뉼러 신스 (`tracker/granular.py`) — grain/density/pitch/spray/tone/scramble,
  touch·merge 클릭 트랜지언트, 오프라인 렌더 테스트 5종
- [x] 마우스 샌드박스 (`tracker/sandbox.py`) — 드래그·회전·추가·삭제, 전체 파이프라인 실시간
- [ ] 샌드박스로 매핑 감도 튜닝 (`sound.mix` 가중치, 스무딩 α) — **직접 들으면서 피드백**
- [x] 프래그먼트 구조: 사운드 4개 x 4조각 = 16개, 오브제 1:1 배정 (왼→오 = 재생 순서,
  오브제 위치 = 조각의 팬, 겹치면 그 조각 침묵) — 6/12 '사운드 동일' 피드백으로 재설계
- [ ] 그레인 소스 교체 실험 (`--wav` 4개) — 실제 쇳소리 녹음 사용
- [ ] (권지수/사운드) docs/osc-map.md 기반 Max 수신 패치 — 내장 신스를 점진 대체
- [x] 세션 녹화(`--record`)·리플레이(`tracker.recorder`) — 트래커 없이 재생, OSC 재송출 지원

**완료 기준**
- 오브제 조작 → 소리 변화 지연이 체감 80ms 이내
- touch/merge 이벤트가 트랜지언트로 들리고 오발이 없음

## Phase 4 — 릴레이 하드웨어 브링업 (8월, 부품 수급은 7월 중 시작)

코드는 준비 완료 — 실물 검증만 남음. docs/wiring.md 의 단계 순서를 따른다.

**준비물 (직접)**: Arduino Uno/Nano, 74HC595 ×18, ULN2803 ×18, 릴레이 모듈 144ch,
SMPS 5V ×3, 배선재 — 7월 중 발주 권장 (리드타임 리스크)

**작업**

- [ ] 발열·전류 측정, 워치독·비상정지 실동작 확인

**완료 기준**: wiring.md 점검 체크리스트 전 항목 통과
