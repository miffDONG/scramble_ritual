# 배선·전원·안전 가이드

## 신호 체인

```
Arduino Uno/Nano
  D11 (MOSI) ──→ 595#1 DS(14)
  D13 (SCK)  ──→ 모든 595 SHCP(11) 공통 버스
  D10        ──→ 모든 595 STCP(12) 공통 버스   [래치]
  D9         ──→ 모든 595 OE(13) 공통 버스     [LOW=출력 활성]
  595#1 Q7'(9) ──→ 595#2 DS(14) ... #18까지 데이지체인
  모든 595 MR(10) ──→ VCC 고정
각 595 출력 8개 ──→ ULN2803 입력 ──→ 릴레이 코일(-)  [코일(+)는 5V 레일]
ULN2803 COM(10) ──→ 코일 5V 레일 (내장 플라이백 다이오드 활용 — 반드시 연결)
```

- 18칩 × 8 = 144출력. 펌웨어는 `buf[17]`부터 송신 → `buf[0]`이 MCU에서 가장 가까운 칩.
- 논리 셀 `i`(row*12+col) ↔ 물리 릴레이 대응은 **테스트 패턴 4(1칸 워크)** 로 실측 확인.
  어긋나면 펌웨어에 리매핑 테이블을 추가하는 편이 배선 재작업보다 싸다.
- SHCP/STCP 버스가 길어지면(>30cm) 33~100Ω 직렬 저항 + 칩당 0.1µF 디커플링 필수.
  체인이 불안정하면 SPI 클럭을 2MHz→500kHz로 낮춰 검증.

## 전원 분산 (SMPS ×3)

| 레일 | 담당 | 부하 (Songle SRD-05 코일 ~72mA 기준) |
|---|---|---|
| SMPS A 5V | 릴레이 코일 1~48ch (열 1~4) | 최대 48×72mA ≈ 3.5A |
| SMPS B 5V | 릴레이 코일 49~96ch (열 5~8) | ≈ 3.5A |
| SMPS C 5V | 릴레이 코일 97~144ch (열 9~12) | ≈ 3.5A |

- 로직(아두이노+595)은 코일 레일과 분리 급전(USB 또는 별도 5V). **GND는 전 레일 공통**(스타 접지).
- 릴레이 접점이 스위칭하는 부하(전자석)는 **별도 전원** — 코일 레일과 절대 혼용 금지.
- 각 SMPS 출력에 퓨즈(5A) + 전해 캐패시터(1000µF) 권장. 돌입전류로 인한 리셋 방지.
- 동시 ON 상한: 호스트 60 / 펌웨어 72 (T_LIMIT으로 조정 가능). 전 채널 동시 ON은 설계상 불가.

## 브링업 순서 (권장)

1. 아두이노 + 595 **1개** + LED 8개로 프로토콜 검증 (`--test 1~4`)
2. 595 18개 체인 + LED로 확장 — 매핑 확인 (`--test 4`)
3. ULN2803 + 릴레이 보드 연결, 코일 전원 인가 — 소수 채널부터
4. 호스트 데모 구동 (`--port ...`) → ACK 실패율·워치독 플래그 확인
5. 장기 가동: 8시간 연속 구동하며 SMPS·릴레이 보드 온도 기록

## 점검 체크리스트 (전시 운영용 초안)

- [ ] 케이블 빠짐 시 1.5초 내 전체 OFF 되는가 (워치독 동작 확인)
- [ ] 호스트 강제 종료 후 재접속 시 정상 복귀하는가
- [ ] `--all-off` 비상 정지 즉시 동작하는가
- [ ] 8시간 가동 후 SMPS·릴레이 표면 온도 < 60°C
- [ ] CRC 오류 카운트(Parser.crc_errors) 증가 추세 없음 — 케이블·노이즈 점검
